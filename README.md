# Proyecto DS2

Aplicación frontend construida con React, TypeScript y Vite.

## Estructura

```text
Proyecto-DS2/
├── public/             # Archivos públicos servidos sin transformación
├── src/
│   ├── assets/         # Imágenes, iconos y recursos importados
│   ├── components/     # Componentes reutilizables
│   ├── data/           # Datos locales y mocks
│   ├── hooks/          # Hooks personalizados
│   ├── layouts/        # Estructuras compartidas de página
│   ├── pages/          # Vistas principales
│   ├── services/       # API e integraciones externas
│   ├── styles/         # Estilos globales y temas
│   ├── types/          # Tipos compartidos
│   ├── utils/          # Utilidades puras
│   ├── App.tsx         # Composición principal
│   └── main.tsx        # Punto de entrada
├── index.html
├── package.json
└── vite.config.ts
```

## Comandos

```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

Consulta [src/README.md](src/README.md) para las reglas de organización internas.
